Decisions 6 & 7: Navigation Pattern & Core Components

We're combining the components (buttons, cards, badges—styled using our previous decisions) with the core navigation layout. Because we have two main platforms (Web for supervisors, Android for foremen), we need a navigation pattern for both.

Option 1: Sidebar (Web) + Tab Bar (Mobile) - Recommended
Matches shadcn-admin heavily. The Web app uses a collapsible left sidebar, allowing full vertical height for data. The Android app uses a bottom tab bar, making it extremely easy for field workers to switch tasks with one thumb.
